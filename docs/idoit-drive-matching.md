# i-doit drive synchronization

LanLens writes one entry per detected disk in `C__CATG__DRIVE`, a multi-value category. Windows inventory collects device ID, disk index, serial number and firmware. Linux uses the observed block-device name. Repeated or placeholder serial numbers are not used as unique identities. Disk titles include the detected locator; older model-only snapshots receive observation labels that preserve multiplicity but do not establish persistent physical identity. A fresh Deep Scan or updated Windows Agent report is recommended for reliable identification. The original model remains in the title. Existing entries are updated only using a unique serial or explicit locator/mount point; matching model names alone is not sufficient. Conflicting/ambiguous matches are rejected. Each disk save is verified by reading the category again. Failed writes are not split into untracked partial rows. Existing entries are not deleted; legacy model-only records that lack identity may need manual review after the new scan. This synchronizes the observed physical disks, not a separate inventory of Windows logical volumes.

Reference: https://kb.i-doit.com/en/basics/categories/drive.html
